# Evidence Inventory

Mark each area `Reviewed`, `Partial`, `Not Provided`, or `Not Applicable`:
intent/requirements, risk, assertions/oracles, independent oracles,
coverage/mutation, test architecture, data/fixtures, flakiness, CI,
maintainability, escaped defects, generated tests, and agent-built-codebase
risks.

For representative tests, ask whether the test would fail on a meaningfully
wrong implementation, whether expected values are independent of production
logic, whether setup hides behavior, and whether failures are deterministic and
diagnosable.
